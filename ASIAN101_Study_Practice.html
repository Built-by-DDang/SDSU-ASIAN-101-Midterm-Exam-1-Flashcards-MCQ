How to use this as an engineering student
  1. Define → distinguish → apply. For each concept, state what it means, distinguish it from a similar concept, and invent an example. Treat a definition as a specification and an example as a test case.
  2. Flashcards: answer out loud before revealing. Select “Got it” only if your explanation was accurate without hints. A familiar-looking answer is not the same as recall.
  3. Practice questions: write or choose your answer before checking. Explain why the other choices fail. Use the source reference to resolve uncertainty.
  4. Repeat with spacing: review missed ideas later today, tomorrow, and again a few days later. Mix topics after your first pass.
